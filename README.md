# jellydog-plush-store
JellyDog萌物铺玩偶售卖网站-团队实践项目

> 小组 4 人协作开发的电商静态网页项目，基于 HTML + CSS + JavaScript 原生实现，无框架，使用 localStorage 完成本地数据持久化，模拟完整萌物周边购物网站业务流程。

### 项目简介

Jellydog 萌物铺是面向年轻群体的毛绒周边电商原型网站，包含首页、商品分类、商品详情、购物车、登录注册、售后服务、个人中心、订单列表、商品收藏等完整电商模块。

- 技术栈：原生 HTML5、CSS3、JavaScript，localStorage 本地存储
- 团队分工：4 人分工开发不同页面，页面之间互相跳转，数据通过本地存储完成跨页面同步
- 运行方式：直接打开 HTML 文件即可运行，无需后端服务
- 
### 本人负责模块说明（张佳音）

#### 1. 订单列表页 `111张佳音‑订单列表页.html`

1. 读取 `localStorage` 中购物车结算生成的用户订单数据，和示例订单合并渲染；
2. 标签页筛选：全部、待付款、待发货、待收货、待评价订单；
3. 业务逻辑：订单付款、确认收货、商品评价弹窗、删除 / 取消订单；
4. 加载更多分页逻辑，同步更新本地存储订单状态；
5. 交互动效：订单卡片入场动画、按钮 hover 动效、状态标签动画；
6. 返回跳转个人中心，ESC 快捷键返回。

#### 2. 商品收藏页 `111张佳音‑商品收藏页.html`

1. 读取 `localStorage` 的收藏商品数据，兼容缺失收藏时间的数据修复；
2. 支持：全选 / 批量取消收藏、单个取消收藏；
3. 多维度筛选：商品类型筛选、价格区间筛选；
4. 排序功能：按收藏时间、价格升序 / 降序；
5. 卡片 hover 动效、删除退场动画，点击跳转商品详情；
6. 空状态处理，ESC 快捷键返回个人中心。

> 两个页面和其他模块打通：商品详情点击收藏写入本地存储；购物车结算生成订单存入本地存储；个人中心可跳转至订单、收藏页面，数据互通。

> ### 项目功能亮点

1. **本地数据持久化**：使用 localStorage 实现收藏、购物车、订单跨页面数据共享，模拟后端接口数据交互；
2. **丰富交互特效**：卡片入场动画、hover 动效、弹窗动画、列表退场动画，提升用户体验；
3. **完整业务闭环**：浏览商品→加入购物车→结算生成订单→查看订单→商品收藏评价整套电商流程；
4. **响应式适配**：页面做基础响应式，适配电脑、平板、手机不同屏幕；
5. **页面间路由跳转**：各个页面相互链接跳转，形成完整网站原型。
